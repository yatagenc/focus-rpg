# Product Principles

## Mobile First

The app is designed around a narrow portrait phone viewport. Windows desktop is used as a development target, but layouts should behave like mobile screens.

## Fast Entry

The user should be able to open the app, select a save, and start a session with minimal friction.

## Progress Must Feel Earned

XP and gold must come from valid focus time. Short accidental sessions should not grant rewards.

## Calm, Not Noisy

The RPG layer should add motivation without overwhelming the study workflow.

## Expandable Systems

Progression, shop, cosmetics, audio, and AFK checks should be implemented in isolated systems so they can grow without rewriting the app.
