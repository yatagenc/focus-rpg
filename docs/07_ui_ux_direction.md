# UI/UX Direction

## Current Direction

The app should feel like a quiet fantasy productivity tool, not a busy game lobby.

## Layout

- Portrait-first
- Safe around notches and dynamic island areas
- No horizontal overflow
- Main hub center area reserved for future animated ambience

## Interaction Feel

Buttons should eventually feel weighty and tactile, inspired by fantasy card-game UI without copying copyrighted assets.

## Current Screens

- Main menu
- Save slots
- Class selection
- Main hub
- Focus session
- Profile
- Settings
