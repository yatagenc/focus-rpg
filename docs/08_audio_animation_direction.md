# Audio And Animation Direction

## Goal

Audio and animation should support motivation without becoming distracting.

## Planned UI Sounds

- button press
- confirmation
- cancel/back
- session complete
- level up
- gold gain

## Planned Animations

- tactile button press scale
- progress fill animations
- session complete feedback
- level-up burst
- subtle ambient hub background

## Asset Policy

Do not use copyrighted assets from commercial games. Use original assets, CC0 assets, properly licensed packs, or generated assets.
