# Focus RPG Project Vision

Focus RPG is a mobile-first study and focus app that turns consistent study time into light RPG progression. The app should help users start sessions quickly, track meaningful effort, and feel a steady sense of character growth without turning productivity into a distracting game.

## Core Goals

- Make starting a focus session fast.
- Reward valid study minutes with XP and gold.
- Keep profile progression persistent across app launches.
- Support multiple local save slots.
- Build toward a polished fantasy atmosphere with audio, animation, and ambient backgrounds.

## Non-Goals For The Current Phase

- No AFK detection yet.
- No real shop economy yet.
- No cosmetic rendering yet.
- No multiplayer or cloud sync yet.
- No production-grade visual polish yet.

## Current Product Shape

The current app contains a main menu, save slots, class selection, main hub, settings, focus session flow, profile stats, session persistence, XP progression, and early economy rules.
